# Security Policy

## Supported Versions

The current supported release is [NetworkM 1.0.0](https://github.com/EduGeyser/NetworkM/releases/tag/v1.0.0).
Security fixes are developed on `develop` and published in new releases.

## Reporting a Vulnerability

Use this repository's **Report a vulnerability** action to report vulnerabilities
privately. See GitHub's [private reporting instructions](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)
for details. If the action is unavailable, open an issue asking for a private
contact method without including vulnerability details.

The maintainer will review the report and keep the reporter informed while
investigating and developing any required fix.

The maintainer and reporter will agree on a disclosure timeline after the fix
is available.
